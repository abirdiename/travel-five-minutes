# Там на пять минут

Дизайн-прототипы интерактивной истории Яндекс Командировок.

- `index.html` — первая версия.
- `pixel.html` — версия в стиле пиксельной игры.

Оба файла самодостаточны. Обычная прокрутка управляет историей; сайт ничего не бронирует и не отправляет. Время 03:00 — условный сюжет с ожиданием ответов, не замер и не норматив.

Кнопка демо ведёт на существующий учебный прототип; его доступность зависит от доступа к внутреннему адресу.
